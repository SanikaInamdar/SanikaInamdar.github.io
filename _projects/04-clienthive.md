A platform for service providers — chartered accountants, lawyers, policy agents, faculty — and their clients, for one-to-one secure document sharing, appointment scheduling, and video and text chat, on both web and app. Built with a team at PICT (April 2023).

- built the Next.js website with Firebase Google Sign-in authentication
- integrated the Node.js APIs for document upload/download and appointment scheduling
- added video calls using the 100ms SDK

**Stack:** Next.js, Node.js, Express.js, Prisma ORM, Firebase, Tailwind CSS
