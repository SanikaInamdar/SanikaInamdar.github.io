A platform that connects investors and entrepreneurs for equity-based business investments, based on start-up portfolios. Built with a team at PICT (Feb–May 2022).

- integrated Node.js REST APIs and dynamic routes
- built modular, component-based UI and page layouts
- implemented JWT-based authentication and authorisation
- made the site responsive and accessible

**Stack:** React.js, Node.js, Express.js, MongoDB, Tailwind CSS

website live at <a href="https://pitch-n-fund-website.vercel.app/">Pitch&Fund</a>

code available at <a href="https://github.com/SanikaInamdar/pitch-N-fund-website">repo</a>
